# 🏨 TourSafe Hotel Portal

Hotel management portal for tourist registration, onboarding, and safety monitoring.

---

## Overview

The Hotel Portal enables hotel staff to register tourists, manage travel information, and initiate onboarding workflows that support tourist safety and emergency response coordination.

---

## Features

- Tourist registration and onboarding
- Travel information management
- Emergency contact collection
- Guest monitoring dashboard
- AI-generated safety briefing integration
- Real-time tourist status tracking

---

## Tech Stack

- React.js
- JavaScript
- Axios
- React Router
- CSS
